A 區 OSC 轉送服務

TD 沿用已完成的 A_CENTER_OSC.51 與 B_SIDES.32（或更新版本）。本次不需改 TD。
手機開 https://vistwinproject.github.io/A-Web/A_ZONE_OSC.html

啟動轉送服務：
方法一：A_OSC_RELAY.py 與 START-RELAY.cmd 放同一資料夾，雙擊 START-RELAY.cmd。
方法二：將 A_OSC_RELAY.py 全部貼進 TD Text DAT，按 Run Script。
重複 Run Script 會關閉該份程式自己的舊服务再啟動。重開 TD 後需再執行。
關閉：在 TD 文字埠執行 import builtins; builtins._ac_a_zone_osc_relay.stop()。

右上「OSC 設定」保留完整欄位：
轉送服務網址：http://192.168.200.143:8788（也可填電腦 IP 或完整 HTTPS 網址）
TD IP：192.168.200.143；轉送與 TD 同機時可用 127.0.0.1
UDP Port：9200
回傳 Port：9202
幕次 OSC 位址：/ac/scene，Scene 1–5 的 int32 為 0–4
A 區開關 OSC 位址：/ac/view，NO_VIEW=0、顯示=1
「連線／讀取設定」讀取現有設定；「儲存並連線」套用欄位，保存 config.json。
若自行改通道，TD 接收端也須接受相同 OSC 位址。
回傳 Port 被其他程式佔用時保留原設定。

主面板「自動／手動」：
服務每次啟動預設自動。Scene1 21.16秒 → Scene2 8秒 → Scene3 等待手勢／手動
→ Scene4 13秒 → Scene5 30秒 → Scene1。
點「播放設定」才會展開秒數欄位；第三幕固定等待互動，不會計時跳到第四幕。
手動模式每幕維持原本 loop，任意按鈕可直接選幕。
01／02／03／04／05 分別送出 0／1／2／3／4，固定對應 Scene1–5。
手動模式忽略手勢網頁的切幕要求；每次按自動，都先切回 Scene1，收到回報後重新計時。
計時由轉送服務執行，手機離開頁面也能繼續；需保持轉送服務與 TD 運行。
NO_VIEW 或 TD 失聯時暫停輪播，重新顯示／連線後目前幕次重新計時。
秒數保存 playback.json；修改秒數重新計時，影片和發光效果不重播。
不修改 TD SHOW_ctrl，只送原本 /ac/scene、/ac/view，沿用 A→B 和地面同步。
不要同時執行兩份控制同一台 A 的轉送服務，以免兩組計時器互相切幕。

Web TCP 8788、OSC UDP 9200、回傳 UDP 9202。
程式僅轉送 A 區控制與接收回報，沒有網頁執行 Python 的入口。
手機與轉送電腦需要網路互通；若瀏覽器要求區域網路存取，選允許。
如瀏覽器阻擋 HTTPS 網頁到區網 HTTP，可使用手機信任的 HTTPS 轉送服務：
python A_OSC_RELAY.py --cert cert.pem --key key.pem
網址填 https://192.168.200.143:8788，憑證需包含该 IP 並已被手機信任。
